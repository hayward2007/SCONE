# 모의 심사 후 개선점과 반영 내역

검토일 2026-09-12. 대상은 SCONE 6족이다. 이 평가는 저자를 위한 모의 심사이며 실제 ICRA 심사위원의 판정이 아니다.

## 채택 가능성 판단

**수정 후에도 현 상태의 채택 가능성은 낮다고 판단한다.** 자체 점수는 ICRA 척도의 **C- / 2.5 (Reject)**를 유지한다. 원고의 이해도와 증거 추적성은 좋아졌지만 기여의 독창성과 실험의 외적 타당성은 글·사진의 양으로 해결되지 않는다. 물리 기체가 없다는 평가는 철회하고, 정확한 공백을 ‘이번 제어기의 실물 반복 비교가 없음’으로 고쳤다.

개별 논문의 채택 확률을 보정할 실제 심사 데이터나 확률 모형이 없으므로 10%, 30%, 70% 같은 숫자를 사실처럼 부여하지 않는다. 학회 전체 채택률이 있더라도 이 논문의 확률로 사용할 수 없다. 여기서 ‘낮음’은 검토자가 현재 원고의 거절 쪽 판단을 내린다는 뜻이다. [공식 ICRA 평점 체계](https://www.ieee-ras.org/conferences-workshops/fully-sponsored/icra/information-for-icra-reviewers/)

| 상태 | 판단 | 이유 |
|---|---|---|
| 초기 자료를 그대로 조합한 원고 | 거절 위험 큼 | 실물/시뮬레이션/서로 다른 버전의 수치가 섞일 위험, 가까운 선행연구 누락 |
| 이번 수정본 | 표현과 근거는 개선, 여전히 C- 수준 | 개발 단계의 80회 비교·시간 간격 검사·실물 archive를 정확히 분리했지만 주요 실험 공백이 남음 |
| 구성요소별 비교·모델 검증·동결 재현을 추가한 경우 | 경계선으로 올라갈 여지 | 분배·재인덱싱이 필요한 이유와 결과의 재현성이 실제로 입증되는지에 달림 |
| 같은 제어기의 실물 반복 비교와 명확한 선행연구 차이까지 확보한 경우 | 수락을 주장할 근거가 생김 | 결과가 유리하다는 보장은 없으며 새 데이터로 다시 판단해야 함 |

## 이번에 실제 반영한 수정

| 심사에서 나올 문제 | 수정한 내용 | 남은 한계 |
|---|---|---|
| ‘굴림과 보행을 섞는다’는 주장만으로는 새롭지 않음 | Quattroped, TurboQuad, R-Taichi, 2026 stride-level 연구까지 반영. 고정된 유한 호에서 다리별 역할·공유 distal joint의 이동량 분배로 기여를 좁힘 | 벡터 투영 자체는 새 수학이 아님. 구성요소별 제거 실험 필요 |

| 계단 영상과 현재 평지 결과가 혼동됨 | 실물 계단 18·24·30·36초 연속 장면을 별도 그림으로 배치. 역사적 정성 자료임을 캡션에 표시 | 실제 staircase 치수·성공률·제어기 버전·외부 개입 여부는 미확인 |
| 비교가 재현되는지 알 수 없음 | 현재 N/P12/C를 다시 렌더링하고 원래 phase=0의 속도와 1e-9 m/s 이내 일치 확인 | 새 독립 표본 수로 중복 계산하지 않음 |

| 기존 capture가 제출 규격 미달 | 실제 모델을 1280×720, 25 fps로 새 촬영. 실물 원본은 원래 720p/1080p, 30 fps 계열임을 확인 | 새 영상은 내용 검토용 초안이며 PaperPlaza 검사를 받은 제출물은 아님 |
| 원시 속도·효율 지표가 모호함 | 순전방 변위 속도, 명령 속도, RMSE, 절대 기계일, slip을 분리 | 배터리 효율·장시간 안정성은 측정하지 않음 |
| 선행연구 서지가 약함 | 15개 BibTeX 항목과 한국어 참고문헌 해설 작성, 주요 DOI·권호·저자 확인 | ASME 2026 최근접 연구는 출판사 등록 초록까지 검토; 전문 추가 검토 필요 |
| 실제 제출물과 내부 자료 혼동 | 영어 PDF 8쪽, 저자·기관 없는 본문, 영상 별도; 한국어 리뷰·원시 archive는 내부용으로 표시 | 자기 선행 발표의 출판 이력 확인, 최종 저자 검토 필요 |

## 다음 실험의 우선순위

1. **기여의 필요성 검증:** 같은 설정에서 이동량 차감 off, 역할 선택 고정, 재인덱싱 off를 각각 비교한다. 실패도 보존하고 지표·종료 조건을 실행 전에 정한다. 각 조건의 중립 자세와 가능한 속도 범위가 유효한지 먼저 확인한다.
2. **독창성 검증:** Chang & Lin 2026 전문을 읽고 수식·접촉 상태·공중 재배치 방법을 대조한다. 지금의 차이가 단순한 로봇 형태 차이뿐이면 연구 질문을 더 발전시켜야 한다.
3. **실제 접촉 검증:** 단일 다리의 평면 굴림과 계단 모서리 진입/이탈에서 실제 형상을 재현한다. 계단 걸림을 주장할 경우 타이어의 비볼록 접촉 표현과 동일 자원 closed-wheel 비교가 필수다.
4. **새 제어기의 실물 비교:** 안전한 범위에서 N/P12/C를 같은 전원·바닥·하중·명령으로 반복하고 거리, 시간, 관절 추종, 전류/전압을 동기화한다. 외부 전원·테더·사람 개입을 기록한다. 실제 실행 전에는 기구 및 연속 토크 범위를 확인해야 한다.
5. **제출 재현본:** 최신 클래스의 package export와 benchmark 진입점을 연결하고 테스트를 통과시킨 후 동결한다. 파일 해시·의존성·실행 방법을 포함한 익명 자료를 재현한다.

이 항목들은 아직 수행되지 않은 후속 연구다. 이번 작업에서 하드웨어, 모터 설정, 원래 제어 소스 또는 기존 사용자의 수정 파일을 바꾸지 않았다. 추가 수치 실험·영상 렌더링·문서 작성은 새 원고 묶음 안에서 수행했다.
