# SCONE 6족 실물 검증 계획

새 논문의 검증 범위 밖에 남는 가장 큰 항목을 위한 계획이다. 이 문서는 실험 수행 기록이 아니며, 로봇에 명령을 전송하지 않았다.

## 1. 시험 전 고정할 항목

실제 장착 모터의 모델·전압·속도 설정·전류 제한·기어 상태, 링크와 호의 가동 범위, 완성 기체 질량, 외부 전원 또는 배터리 조건, 바닥 재질, 위치 측정 장치와 시간 동기화 방식을 기록한다. 타이어에 실제로 사용하는 부품 버전과 제조 조건도 고정한다. 시뮬레이션의 540도/초 sector 값을 하드웨어 허용값으로 그대로 쓰지 않는다.

모터 허용 속도를 확정한 뒤 IK와 sector를 합한 최종 목표 궤적이 허용 속도·가속도·관절 범위를 만족하는지 비구동 상태에서 점검한다. 제약 위반을 목표값 최종 클리핑만으로 숨기면 접촉 이동량의 합이 어긋나므로, 분배기와 스윙 시간을 함께 조정해야 한다.

## 2. 1차 평지 시험

하드웨어 설정을 고정한 B/U/N 세 조건을 사용한다. 첫 속도는 현재 기체에서 이미 검증된 안정 동작 범위 안에서 정하며, 측정이 가능한 최소 두 단계의 목표 속도를 기록한다. 고속 0.45 m/s를 곧바로 실물 목표로 사용하지 않는다. 각 조건은 최소 10회, 순서는 무작위화하고 같은 하중·바닥·전원 상태를 유지한다. 시험 전 제어기 설정 파일과 실행 소스 해시를 저장한다.

매회 초기 자세·명령 시작·이동 측정창·정지 절차를 동일하게 둔다. 외부 위치 측정 장치 또는 고정된 교정 카메라로 순이동 거리와 경로를 측정한다. 이동 카메라의 화면상 이동이나 보행 주기 계산으로 속도를 대신하지 않는다.

기록할 기본 채널은 타임스탬프, 몸체 위치·자세, 명령 속도, 각 관절 목표/실제 위치·속도, sector 목표·분배량·예측 잔여각, 제어기 상태, 공급 전압·전류다. 접촉 센서가 없으면 영상으로 판단 가능한 접촉 사건을 구분하되, 실제 하중을 측정했다고 표현하지 않는다.

## 3. 사전 정의할 판정

시험 성공을 “전진함”으로만 정의하지 않는다. ① 정해진 시간 동안 명령 거부·넘어짐·사람 보조가 없음, ② 경로와 자세 오차가 사전에 정한 범위 이내, ③ 실제 관절 속도·전류·온도가 지정 범위 이내인지 각각 기록한다. 중단 시점과 이유도 남기고 재시도는 새로운 trial ID로 보관한다. 실패를 삭제하고 성공 영상만 모으면 성공률을 계산할 수 없다.

속도는 정해진 시간창의 순이동 거리/시간, sector 변화율은 명령과 측정치를 구분한다. 전기에너지는 동기화된 공급 전압×전류를 적분한다. 마찰이나 하중의 변동 범위는 이 측정에서 식별한 뒤 추가 실험 범위에 반영한다.

## 4. 계단과 추가 연구

평지에서 제어기 추종과 구동기 제약을 먼저 확인한 다음, 규격을 측정한 단일 단차부터 진행한다. 열린 호의 장점을 주장하려면 닫힌 바퀴 대조군의 외형, 질량·관성, 구동 조건, 유효한 제어기를 맞춰야 한다. 호 내부가 모서리를 실제로 잡는 접촉 사건을 측정하거나 확인 가능한 다각도 영상으로 기록한다.

현재 과거 영상에 이러한 시험 번호·거리 교정·동기 로그를 사후로 붙이지 않는다. 새 실험에는 새 날짜와 제어기 해시를 부여한다.
