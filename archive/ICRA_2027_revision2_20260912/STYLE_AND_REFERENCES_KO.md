# ICRA 문체와 참고문헌 적용 기록

2026-09-12 확인. 타 논문의 문장을 가져오지 않고, 주장과 근거를 배치하는 방식을 적용했다. 실제 ICRA 게재 여부와 논문 전문을 확인한 세 편은 다음과 같다.

| 논문 | 실제로 참고한 방식 | 이번 원고에 적용 |
|---|---|---|
| [Pedipulate, ICRA 2024](https://arxiv.org/abs/2402.10837), DOI 10.1109/ICRA57147.2024.10611307 | 추가 장치의 비용이라는 구체적 문제에서 시작하고, 제어 방법과 실험으로 검증한 기능을 연결한다. | 초록을 문제 → 되감기 제약 → 분배 방법 → 비교 수치 → 검증 범위 순서로 작성. 주어와 동작이 명확한 능동문 사용. |
| [SpaceHopper, ICRA 2024](https://arxiv.org/abs/2403.02831), [공식 저자 페이지](https://spacehoppericra.github.io/) | 시뮬레이션 성능과 실물 실험을 각각의 조건에 붙여 설명한다. | 새 제어기의 모든 정량 결과에 simulation 조건을 명시. 과거 SCONE 실물 영상을 새 제어기의 실증으로 연결하지 않음. |
| [Weng et al., ICRA 2024](https://cyberboticslab.com/publication/weng-2024-standardized/weng-2024-standardized.pdf), DOI 10.1109/ICRA57147.2024.10610064 | 테스트의 공정성과 반복 가능성을 연구 문제의 일부로 다룬다. | 공통 기체·게인·위상·측정창을 명시하고, 실패 및 작동 범위를 함께 보고. 이 논문의 물리적 충격 실험을 구현했다고 주장하지 않음. |

## 문장 수준의 수정

- “The arc does not move the contact”처럼 단정하던 문장을 측정 오차를 포함한 기하학적 근사로 바꾸었다.
- “stable”, “robust”, “efficient”, “optimal”, “first”를 포괄적 수식어로 쓰지 않는다. 제약 준수, 완료율, 추종 오차, 기계적 일의 관측값으로 구체화한다.
- “We present / We evaluate / The results show”의 동사는 실제 수행한 행동에만 사용한다. 실물 기록은 “archival footage shows”로 기술한다.
- 초록 첫머리에 내부 감사, Git 오류, 라이브러리 내보내기 실패를 나열하지 않는다. 재현 방법과 중요한 모델 한계는 실험 방법·토의에 두고, 개발 이력은 한국어 내부 문서에서 설명한다.
- 결과 문단은 결론 한 문장 → 대응 표/그림과 수치 → 그 수치가 지지하는 범위 순서다. 심사위원이 글의 흐름을 따라가며 비교를 판단할 수 있게 했다.
- 그림 캡션에는 조건·시간·표시 방식과 해당 그림이 증명하는 범위를 적는다. 사용자가 요청한 자료는 논문 지면에서 판독 가능한 수로 배치하고 나머지는 영상에 담는다.

## 가장 가까운 연구와 차별성

[Quattroped](https://doi.org/10.1109/TMECH.2013.2253615), [TurboQuad](https://doi.org/10.1109/TRO.2017.2696022), [Rolling vs. Swing](https://doi.org/10.3390/biomimetics10070435), [Stride-Level Hybrid Locomotion](https://doi.org/10.1115/1.4070596)는 반드시 검토해야 할 근접 연구다. 마지막 논문은 출판사 등록 초록과 서지정보를 확인했으나 이번 작업에서 전문을 확보하지 못했다. 따라서 이 논문에 특정 제약이 없다고 단정하지 않는다. 제출 전 저자가 전문의 수식과 비교표를 대조해야 한다.

이번 차별점은 6족이라는 수나 호 모양 자체가 아니다. 한정된 sector excursion과 되감기 시간·속도 제한을 연결하고, 다음 스윙 기회까지의 회전 소모를 예측하여 재인덱싱을 결정하며, 포화 후 남는 접촉 이동량만 관절 보행에 넘기는 구체적 제어 구성이다. 단순 기하학적 제한 G, 예측을 포함한 B, 기존 U를 분리해 이 구성을 검증한다. 이 정도의 차별성이 ICRA에서 충분한지는 실물 결과와 근접 연구 전문 비교가 좌우한다.

## 서지 관리

본문 인용은 `references.bib`에서 관리하며, 모든 인용에 실재 논문 또는 공식 문서를 연결했다. 이전 원고의 15개 레코드를 보존하고 CoACD 및 ICRA 테스트 연구를 추가했다. 본문에서 사용하지 않는 레코드는 참고문헌 목록에 출력하지 않는다. 저널명, 연도, 권호와 DOI를 확인했으며 RA-L, IROS, 저널 논문을 ICRA 정규 논문으로 표시하지 않았다. Pedipulate와 SpaceHopper는 문체 참고용으로 이 문서에만 기록하여, 기술적으로 무관한 본문 인용을 늘리지 않았다.

외부 논문 PDF는 분석용 임시 폴더에만 두었다. 배포용 폴더에 타인의 논문 전문이나 그림을 복사하지 않았다. 논문에 사용한 사진·영상은 프로젝트 내부 자료이며, 새 차트와 시뮬레이션 캡처는 이번 실행에서 생성했다.
