두 메시 모두 **로컬 z축이 출력축이고 원점이 축 위에 있다.** 상단 슬랩이 Ø22 보스 → Ø8 샤프트로
좁아지는 것을 확인해 정한 규약이며 추측이 아니다.

배치는 §11.1/§11.2의 관절 축에 그대로 올렸다. 부산물로 **문서 검증이 하나 나왔다**:
조향 모터를 축 위에 올리면 몸통 좌표 기준 하우징 중심이 `(±36.7, ±160, 3.3)` 에 떨어지는데,
이것은 문서 파라미터 `body_hip_motor_center_x_mm = 36.7`, `body_hip_motor_center_z_mm = 3.3` 과
**정확히 일치한다.** 실물 형상과 문서 수치가 독립적으로 맞아떨어졌다.

부채꼴 모터는 축 방향으로 밀어 케이스 앞면이 클레비스 바깥면(`|y| = 143`)에 오도록 두었다.
근거는 `track_half - (b/2 + clevis_gap + clevis_arm_t) = 160 - 17`.

질량은 데이터시트 값(77 / 82 / 82 g)에 맞춘 균일 실효밀도로 넣었다. **형상은 실물이지만 내부
질량 분포(감속기·PCB·자석)는 실물이 아니므로 관성은 예비값이다.**

## 4. 되돌린 것

모터를 부모 링크에 **강체 조인트로 묶었더니 Fusion이 조립을 다시 풀면서 모터 12개를 전부
대각선 반대 모서리로 옮겼다.** 조인트를 지우고 좌표만 다시 지정했고, 별도 호출에서 재확인해
안정적임을 확인했다. 운동학적 부모는 메타데이터(`MARC_REVIEW/kinematic_parent`)로만 남겼다.
**모터가 관절을 따라 움직이게 만드는 것은 B06/D1 과제다.**

주의: Fusion의 오컬런스 이름(`...:1`, `...:2`)은 호출 사이에 재배정된다. 이름으로 다리를
식별하지 말고 **변환 원점의 부호**로 식별한다.

## 6. 남은 것 — 다음 실행 순서

1. **I02 (최우선).** 혼(HN12-N101)·베어링·장착면 도면. 요크 재설계와 프레임 모터 포켓이 전부 여기에 걸려 있다.
2. **요크 #1/#2 재설계.** 최소 59.6×54.1×44.6 / 55.5×51.4×37.5 (모터 + 9 mm/축). 현재 포락으로는 모터가 안 들어간다.
3. **프레임 모터 포켓.** 조향 모터가 프레임 빔·리브·판을 관통 중(정점의 20.9%). 포켓을 파야 한다.
4. **포크 실부재화.** `_STUDY_`의 포크 포락을 실제 팔로 만들고 질량을 집계에 넣는다. 클레비스 절삭 규칙은 §4.1에 확정되어 있다.
5. **스핀축 관성 1.41% 초과 해소.** `web_pocket_fraction`을 D1 후보로 열거나, 2.2e-3 목표를 b=44 시절 값이라는 근거로 재산정한다. 둘 중 하나를 **근거와 함께** 고른다.
6. **모터를 관절에 종속시키기 (B06).** 강체 조인트는 위 4절의 이유로 실패했다. 부모 컴포넌트 안에 넣는 방식은 중첩 오컬런스의 `transform2`를 설정할 수 없어 막혔다. 다른 경로를 찾아야 한다.
7. 그 뒤 B09의 P01–P06 경로와 B10.
